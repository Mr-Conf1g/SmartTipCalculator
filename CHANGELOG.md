# Historial de Cambios (Changelog)

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.1.0] - 2026-11-19
### Modificado
- Se refactorizó la experiencia de usuario (UX) para usar cálculo automático en tiempo real en lugar de requerir un botón de cálculo manual.
- Se eliminó el botón "Calcular" redundante para una interfaz más limpia.
- Se actualizaron los protocolos de memoria interna de la IA para un mejor seguimiento del estado.

## [1.0.0] - 2026-11-18
### Agregado
- Lanzamiento inicial de SmartTip Calculator.
- Cálculo de propinas en tiempo real (10%, 15%, 20% y personalizado).
- Validación de inputs (no se permiten números negativos ni cero).
- Mensajes de error mostrados directamente en el DOM (sin `alert()`).
- Diseño responsivo con variables CSS.
- Desarrollo 100% en Vanilla JS (ES6+).
